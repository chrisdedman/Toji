# Toji

A Mac app for looking after what Homebrew has installed: updates, apps, tools, services and storage, without the Terminal.

## Download

Get the latest version from [Releases](https://github.com/chrisdedman/Toji/releases/latest).

- **Toji-x.y.z.pkg** installs Toji in Applications.
- **Toji-x.y.z.zip** is the app on its own; unzip it and drag it to Applications.

Toji needs macOS 26 or later. It is not yet notarized by Apple, so the first time you open it macOS will block it: open System Settings › Privacy & Security and choose Open Anyway.

Once installed, Toji checks here for new versions and offers to install them.

This repository holds releases only.
